# Golden regression corpus

`scripts/golden.sh check` builds a `.bpi` for every graph in `graphs/` under every config in
`configs.tsv`, answers `queries/<graph>.tsv` from it, and compares the
SHA-256 of the image and of the answers with `manifest.tsv`. For every graph it also runs the paths
that build no index (`query --engine dijkstra`, the in-memory `query --engine dp` build and
`--compare-whole-graph-dijkstra`) and requires their answers to equal the index's. It needs bash 4
and GNU coreutils; `BIN` picks the binary (default `target/release/biopath`) and `WORK` the scratch
directory (default `target/golden`).

A refactor that is meant to be byte-identical must pass `check` unchanged. A change that alters the
image on purpose re-records with `scripts/golden.sh record` (which also checks every answer against
whole-graph Dijkstra) and states why in the commit message.

The `forced` configs lower the tier thresholds so labels, S-node segment trees, projection tables
and the per-block pipeline for small blocks run on the tiny graphs; the `-prefix` / `-segtree`
variants pin the block-cut lift backend. Every config builds at word size 32;
`tests/image_determinism.rs` covers 64.

Graph sources:

- `chain5`, `GCA-41.clean.largest-block`, `paper_bridge`, `rnode_selfflip`, `tiny1`, `twoflip`,
  `twoflip_hub`, `two_triangles`, `two_triangles_hairpin`: the engine's fixtures
  (`engine/test_files/`).
- `gbz_small`: `test_files/gbz/small.gfa` (generated by `test_files/gbz/make_small.py`).
- `vgcmp_tiny`, `vgcmp_bubble`, `bubble_internal_to_boundary`, `bubble_nonminimal_branch`: small
  graphs written while comparing answers with vg's distance index.
- `cactus-BRCA2`, `micb-kir3dl1`, `linked_cycles`, `thread_determinism`, `gfaz_example`: test
  graphs from the vg repository, MIT licence ([`graphs/LICENSE-vg`](graphs/LICENSE-vg)).
